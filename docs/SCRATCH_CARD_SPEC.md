# Scratch cards: term access

One card unlocks unlimited Terminal Result viewing and printing for one student, academic session and term. Progress reports remain free. The configured price is unchanged. PIN activation and admin revocation still apply. Previously exhausted cards are accepted; historical counters are retained but no longer increment or restrict access. No database migration is needed.

Online checkout is initialized server-side with PAYSTACK_SECRET_KEY and SCRATCH_CARD_ONLINE_ENABLED (or the developer setting). The browser redirects to Paystack’s returned checkout URL; no public key or popup script is needed for this flow. Paystack returns to /student/scratch-card-payment, which verifies the reference through the authenticated server endpoint. Webhooks and pending-payment recovery remain supported. Only successful NGN payments for the exact order amount unlock access. A valid account email is required. Test checkout and callback on the deployed domain before live rollout.
